# Consigne 06 · Refactorisation

La refactorisation est le geste qui recule le plus vite quand on code
avec un agent. Celle-ci se demande explicitement.

---

Refactorise le code ci-dessous **sans changer son comportement
observable**. Les tests existants doivent passer sans être modifiés ;
si tu dois en modifier un, c'est que tu changes le comportement :
arrête-toi et dis-le.

Objectifs, dans cet ordre :

1. Supprimer la duplication réelle, pas la ressemblance de surface
2. Réduire le nombre d'états possibles
3. Rendre les noms exacts
4. Sortir du composant ce qui n'est pas de l'affichage

Présente le résultat en deux parties : la liste des changements avec
leur justification en une ligne, puis le code complet.

Ne profite pas de l'occasion pour ajouter une fonctionnalité, changer
le style, ou introduire une bibliothèque.

```
[colle le code ici]
```
