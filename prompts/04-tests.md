# Consigne 04 · Tests

---

Écris les tests du composant ci-dessous avec Vitest et Testing Library,
déjà installés dans le projet.

Teste le comportement visible par l'utilisateur, jamais les détails
d'implémentation : pas d'état interne, pas de nom de fonction privée,
pas de sélecteur par classe CSS. Utilise les rôles et les libellés
accessibles.

Couvre, au minimum :

- le cas nominal, du remplissage jusqu'à la confirmation
- chaque règle de validation, une par test
- l'échec réseau, et le fait que la saisie n'est pas perdue
- l'état d'attente pendant l'envoi

Un test, une assertion principale. Nomme chaque test par la phrase
qu'il vérifie, en français.

```
[colle le composant ici]
```
