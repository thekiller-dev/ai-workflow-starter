# Étape 4 · Assumer

> Je teste, je sais l'expliquer, je signe.

## Les quatre jalons

| | |
| --- | --- |
| 01 · Je l'ai testé | pas seulement le cas qui marche |
| 02 · Les erreurs sont gérées | réseau, saisie, serveur |
| 03 · Le code mort est parti | imports, essais, variables |
| 04 · Je peux l'expliquer | ligne à ligne, sans le chat |

Un seul jalon non franchi, et la tâche retourne au cadrage. Ce n'est
pas une punition, c'est le critère d'arrêt.

## La phrase

Elle s'écrit au début, dans la spécification, et se relit à la fin. Si
on doit la réinterpréter pour se déclarer satisfait, c'est qu'elle
était mal écrite.

## Le commit

Un commit par tâche, message à l'impératif, en français, sans mention
de l'outil qui a aidé. Ce qui compte dans l'historique, c'est ce que
fait le code, pas comment il a été tapé.

```
Ajoute le formulaire de contact avec validation et gestion d'erreur
```

## La question qui tranche

> Si tous les agents IA disparaissaient demain, saurais-tu expliquer,
> corriger et faire évoluer ce code ?

Si la réponse est non, la tâche n'est pas terminée. Elle est livrée.
Ce n'est pas la même chose.
