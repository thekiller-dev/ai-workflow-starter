# Consigne 07 · Message de commit

---

Propose un message de commit pour le changement ci-dessous.

- Une ligne de titre, à l'impératif, en français, soixante-douze
  caractères au maximum, sans point final
- Pas de préfixe technique, pas d'emoji, aucune mention d'un outil ou
  d'un assistant
- Si le changement le mérite, un corps de deux ou trois lignes qui dit
  pourquoi, jamais comment

Exemples de titres attendus :

```
Ajoute le formulaire de contact avec validation et gestion d'erreur
Corrige la perte de saisie après un échec réseau
Extrait l'appel d'envoi dans une fonction dédiée
```

```
[colle le diff ici]
```
